# 票 03 — TUI 第 6 页「备份」

## What to build

broker TUI 加第 6 页「备份」:状态区(配置摘要/备份文件列表/新鲜度/调度只读探测)+ 三个动作(立即备份/校验最新/编辑配置)。owner 不记命令即可看备份状态、点一下备份与校验、改配置且校验与命令行一致。客户端角色 TUI 不显示此页。

## 验收标准

- [ ] 页数组 5→6,Tab 循环覆盖;客户端角色入口不构造此页(角色门控测试)
- [ ] 状态区:配置摘要(目录/保留份数/口令文件路径);`*.sme` 时间倒序列表(最近 10 份+总数);最新一份 >25 小时警示态;计划任务 `sshmgr-backup` 只读探测(已装/未装,不做任何写操作)
- [ ] 配置缺失:整页引导态,仅 [e] 可用
- [ ] [b] 立即备份:后台跑与 CLI 同一条 create 逻辑(同校验/锁/轮转),完成后刷新列表,失败原因(如 marker 缺失/世代不一致)在状态行可见
- [ ] [v] 校验最新:试解密+重解析;成功报完好;解密失败报失败(呈现措辞按实现裁量,不强制"损坏/口令不符"三分——评审 F9 留档,vaultio 设计上二者不可区分)
- [ ] [e] 编辑配置:huh 表单三字段(目录/保留份数/口令文件路径);保存前三道校验逐一生效——①两路径绝对路径 ②口令文件子树禁入 ③dir 已有 .sme 时口令试解密最新一份;任一失败阻断保存并给人话报因;通过后原子写 backup.json
- [ ] 页面契约测试:键位分发、列表刷新、三道校验各失败分支、引导态,沿用既有 TUI 测试基建

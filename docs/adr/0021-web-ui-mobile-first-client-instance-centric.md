# 权威端 Web UI 改为手机优先、以服务器与客户端实例为管理对象

2026-11-18 grilling 定案。v0.22.0 的权威端 Web UI 照搬数据表组织页面：主页即服务器列表，「访问」下并列 Profile、配对、项目令牌、设备码四个入口，新增服务器有五个入口且是一张混合连接、凭据、拓扑、元数据与授权的长表单，手机上表格折叠后丢列名。owner 无法回答「在哪录入一台服务器」「哪些客户端拿到了哪个 profile」这类最基本的问题，导致机密项、共享存储、软件清单发布后无从使用。我们决定按 owner 的心智模型重组信息架构，并以手机竖屏为主设计。

## Decision

**一、一级导航固定为五个标签：主页 / 服务器 / 客户端 / 授权 / 更多。** 主页是状态总览（待审批配对、需要注意的服务器、软件清单待办、计数、醒目的「添加服务器」），不再罗列入口。「授权」下是 Profile、机密项、共享存储三个子页；「更多」下是软件清单总览、网络拓扑、运维与高级。手机上为底部标签栏，桌面为顶部横排。

**二、客户端实例是界面上的管理对象，设备码降为它的凭据属性。** 「客户端」页列出全部客户端实例及各自的 profile、最后拉取时间、版本、来源；待审批配对也在这里。客户端详情可就地更换 profile（确认前显示可见服务器的增减），移除客户端即吊销其设备码与配对生成的项目令牌。手动签发的项目令牌（界面称「MCP 访问令牌」）与手动签发设备码收进「更多 → 高级」。

**三、服务器详情是一台服务器的全部视图**，分连接、网络位置、授权、软件四块；授权块就地查看与开关它所属的 profile、可写入的机密项、可挂载的共享存储。资源一侧（Profile、机密项、共享存储详情）反向查看与批量勾选服务器，并显示实际能拿到该资源的客户端。两个方向改的是同一份数据，共用同一个服务器勾选组件与确认页。

**四、新增服务器只有一个分步流程**：连接与登录 → 网络位置（可跳过）→ Profile（可跳过）；元数据在详情页补。拓扑页的上下文新增进入同一流程并预选机器与网络。删除类型选择页。

**五、取消服务器元数据 Location 字段**，「在哪」统一由网络拓扑的地点（原称站点）表达；已有 Location 文本迁移追加到 Description。`list_servers` 改为给出由拓扑推导的地点名。

## Supersedes

- ADR 0010 的「桌面优先、手机可用」：改为手机优先，只有拓扑图拖拽编辑仍只在桌面提供。
- ADR 0003 中「`cache-tokens bind` 只留命令行」：更换客户端实例的 profile 进入 Web UI；命令行等价面约束本身不变。
- ADR 0005 中「六个元数据字段」：改为五个，去掉 Location。

## Considered Options

- 保留按数据表组织的入口，只修手机样式：被否——混乱的根源是名词（设备码、项目令牌、配对三者并列）与入口重复，样式修好仍然看不懂。
- 服务器列表按机器（拓扑设备）而非登录条目分组：被否——绝大多数机器只有一个登录条目，按条目列出符合直觉；同机的其他条目在详情的网络位置块列出。

## 补充:地点多级、地址随连接信息一并录入(2026-11-18 第一批 mock 评审)

owner 看第一批 mock 时指出:不知道在哪新建和查找地点;「网络成员」看不懂,录入连接地址时本就该一并填物理局域网和虚拟局域网的地址;地点没有包含关系(公司下有多个厂区、厂区下有多栋楼);「同机的其他登录条目」看不懂。据此:

- **地点改为多级树**,层数不限;设备直接登记自己的地点,物理局域网另登记覆盖的地点,两者不一致只提示。这改变了「设备在哪由物理局域网推导」的旧做法,需要存储迁移(旧数据:设备地点取其物理局域网的地点)。
- **地址列表取代单个地址框**:新增服务器第一步按「网络 + 地址」逐行填写,「其他(不属于已登记网络)」一行对应原兜底地址;「网络成员」一词不在界面出现。第二步只剩地点选择。
- **地点就地新建 + 集中管理**:所有选地点处是可搜索的树形选择器,可当场新建;「更多 → 地点与网络」集中管理地点树与网络。
- **同机多账号自动识别**:新增时地址与已登记机器重复才询问是否为同一台机器上的另一个账号;界面称「同一台机器上的其他账号」,不存在时不显示。

## 补充:第二批 mock 评审(2026-11-18)

- **机密项与共享存储备注必填**:agent 经 `list_secrets` / `list_shares` 只能靠备注判断用途,空备注等于无法推断。新建时必填;存量空备注列入主页待处理;凡出现处在名称下显示备注首行。
- **私钥以上传文件为主**,粘贴内容退为备用链接。
- **客户端详情显示所在机器及其软件清单**;未关联机器时可就地选择或新建机器(沿用设备至多关联一个客户端实例的既有约束)。

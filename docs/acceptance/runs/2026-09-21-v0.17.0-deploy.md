## P3 三新功能首验

### ① owner 变更命令入审计（票 02/03/04 九命令；A6「revoke 有痕」子判据补验）

全部经 SSH 工具面在 NUC10 执行：

```
$ sshmgr cache-tokens add --name tmp-v017 --profile e2e-profile
Authorization code for "tmp-v017" (shown once): <一次性授权码,不入册>
Server fingerprint (serve cert SPKI): sha256:c69b2560…

$ sshmgr cache-tokens revoke tmp-v017
revoked cache token tmp-v017 (status=revoked)

$ sshmgr audit --action cache-token.revoke
2026-09-21 12:30:15+08:00  (none)  (owner)  cache-token.revoke  ok  exit=0  0ms  {"name":"tmp-v017"}
```

审计行字段齐（action=cache-token.revoke / operator=(owner) / status=ok / 明细 JSON）。**验收册 Plan 48 A6「revoke 有痕」子判据真机闭环**——首轮（v0.16.0）该子判据不满足已登记，本批修复后实证。`cache-tokens ls` 终态核对：tmp-v017 status=revoked。

### ② `cache instances rm --yes`（无人值守等价面）

本机执行，前后 `cache instances ls` 对照：

```
$ sshmgr cache instances rm plan48drill --yes
已删除实例 "plan48drill"(槽目录与 DEK 均已清理)。
配套两件事本机 rm 无法代劳:
  1. broker 侧吊销该设备码(client 无权远程吊销):sshmgr cache-tokens revoke plan48drill
  2. --write-mcp 写在槽外的 .mcp.json 副本不随 rm 清理——……请自行删除
```

删后 ls 中 plan48drill 行消失（Train3060 半态槽与 agentA DEK 孤儿为 owner 可选清理项，未动）。配套提示第 1 件已核：broker 侧 `cache-tokens ls` 显示 plan48drill **试点时已吊销**（status=revoked），无需再操作。

### ③ 服务器 id 大小写近邻提示

`mcp --cache` 新进程（驱动脚本）对错抄 id `mYmgHCZUMeE`（正确为 `mymgHCZUMeE`，第二位大小写之差）发起 `exec_command`：

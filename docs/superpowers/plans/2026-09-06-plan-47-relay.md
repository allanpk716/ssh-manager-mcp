# Plan 47: relay_file 大文件中继 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增第 12 个 broker MCP 工具 `relay_file`——50GB 级大文件经 broker 零暂存分块流式中继(服务器↔服务器 / broker 本机→服务器),断点续传锚在接收端 Manifest,进度经 Plan 32 任务表 `exec_output` 轮询;销 backlog #46 + upload_file 1 MiB 单文件债根因。

**Architecture:** broker 内双 SFTP 端点 offset 流式管道(256 MiB 块,内存 MiB 级与文件大小无关);`<to>.sshmgr-partial` + `<to>.sshmgr-manifest.json` 落 B 端目标同目录;任务表复用(ReserveRelay 超集原语 + runTask 终态纪律 + notifyWriter 进度);提交点 = 最终 PosixRename(partial→真名);posix-rename@openssh.com 硬依赖(探测不支持即拒)。

**Tech Stack:** Go 1.25;`github.com/pkg/sftp` v1.13.10(HasExtension/StatVFS/PosixRename);`github.com/modelcontextprotocol/go-sdk/mcp` v1.2.0;既有 testsshd/eval/conformance 设施。

**Spec:** `docs/superpowers/specs/2026-09-06-plan-47-relay-design.md.rev4.md`(**第五版 owner 定稿**,四轮盲评 52 簇收敛;执行者必读,冲突以 spec 为准)+ `docs/adr/0001` + 根 `CONTEXT.md` 术语。

## Global Constraints

- **零暂存铁律**:broker 磁盘零用户数据读写(本机源=读源本身);内存=流式缓冲,禁任何块级全量缓冲。
- env seam:`SSHMGR_TRANSFER_CHUNK` 默认 `256<<20` 钳 `[16<<20, 1<<30]`,`SSHMGR_TRANSFER_PARALLEL` v1 只接受 `1`——非法即构造失败(fail-closed),**解析先于 tunnels/tasks manager 构造与 StartSweeper**(spec §4);serve 侧 `NewServeRunner` bind 前验证。
- `relayRunCap = 72h` 常量,不设 env;`relayMaxChunks = 16384` 常量;**块数求值溢出安全**(q/r 形态,禁 `(size+chunk-1)/chunk`),size<0 拒。
- **posix-rename 硬依赖**:stage 0 `HasExtension("posix-rename@openssh.com")` 零 IO 探测,不支持即终态 failed;**无 Remove+Rename 回退**;续传路径**无试探 rename**(首跑空清单落盘即活探针)。
- 键构成:**write 键 = `to_server_id + "\x00" + canonical 工件路径`、read 键 = `from_server_id + "\x00" + canonical 源路径`**(四判定矩阵同构键空间);远程 canonical = `path.Clean`(禁 filepath/ToSlash),本机 = `filepath.Clean`;本机源不进 read-set。
- preflight **同步段零远端 mutation**(MkdirAll/fresh 删除/空清单全在引擎 stage 0,以 ⑧ 租约为前提);连接自 ③④ 起挂 defer 双 close,insertLocked 成功才移交。
- 审计:start 行 `relay %s:%s -> %s:%s (%d bytes, %d chunks, resumed %d)`(本机源=`local`),end 行 = taskID;statuses 两行分列(spec §6);**内容零过境**(审计/工具返回/exec_output 三面零文件内容,反向断言)。
- 复制形态钉死 `io.CopyN(dst, src, min(chunk, size−offset))`;末块后 EOF 确认;块哈希 TeeReader 边传边算(源零额外读)。
- file_sha256 判据 = **本任务 byte 0→EOF 连续流式**(含空清单自愈态),非 fresh 参数;resumed 任务只报 merkle 根。
- **upload_file / upload_content / download / exec 全部零行为变化**(回归锚);upload_file 既有四债零回补。
- eval 与 conformance **双重门控**(无环境自动跳过,不判失败)。
- 每 task 末 scoped 测试绿 + commit(尾行 `Co-Authored-By: Claude Opus 4.8 (1M context) <noreply@anthropic.com>`);T7 末全量 `go test ./...`。Windows 上禁无起始路径 `find`;本 plan 全程无远程操作。

**Interfaces:**
- Consumes: `Client.c`(*ssh.Client)、`sftp.NewClient` watchdog 模式(upload.go 先例)。
- Produces(T4/T5 依赖):
  - `func (c *Client) RelaySFTP() (*sftp.Client, error)`(带 ctx watchdog 的 sftp client 构造,close 责任在调用段)
  - `func (c *Client) RelayPosixRenameOK(sc *sftp.Client) bool`——`sc.HasExtension("posix-rename@openssh.com")`
